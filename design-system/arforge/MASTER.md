# Arforge UI Design System

> Status: approved baseline  
> Scope: Electron desktop first, shared with Web through the same SolidJS component system  
> Source of truth: user decisions captured during the UI/UX review, supplemented by `ui-ux-pro-max`

## Product character

Arforge is a professional, content-dense AI development workspace. The interface should feel calm, precise, native, and distinctly Apple-inspired without copying macOS controls wholesale. Glass is structural, not decorative: it clarifies layers while keeping code, diffs, terminal output, and long conversations highly legible.

### Approved shell direction

- Use a macOS-style desktop window shell, iPadOS-style split-view information architecture, and iOS-style controls and motion details.
- Use a persistent 56px project rail that can expand into a 260px sidebar, plus a fully hidden focus mode.
- Size project-switch targets at `40px` on fine-pointer desktop layouts, increasing them to the iOS-standard `44px` below `768px` or whenever the primary pointer is coarse.
- Clip project artwork and fallback avatars to a `32px` iOS-style squircle with an `8px` radius and a faint top inner highlight; status and activity indicators remain above the artwork.
- Mark the selected project with a neutral glass plate and a `0.5px` inner hairline around the hit area; do not add a colored side indicator or resize the project artwork.
- Space project-rail entries on an `8px` vertical rhythm.
- Keep the add-project action in the scrolling project flow, separated from the final project by `12px` of open space and no divider.
- Render add-project as a transparent adaptive hit area (`40px` desktop, `44px` narrow/coarse pointer) with an `18px` neutral plus; reveal only a restrained glass fill on hover or press.
- Use mixed project-status indicators: a `6px` blue dot for unread activity, distinct `10px` shapes for permission (amber diamond) and error (red circle with an ×), and a `12px` Spinner for running work. Prioritize permission, then error, then unread when multiple notification states coexist.
- Keep Settings as the only direct utility action at the bottom of the project rail. Move Shortcuts and Help/feedback into an adjacent More menu trigger; use `40px` desktop and `44px` narrow/coarse-pointer targets, with `36px`/`44px` menu rows respectively.

## Foundations

### Color

| Role     |                 Light |                       Dark | Usage                                                 |
| -------- | --------------------: | -------------------------: | ----------------------------------------------------- |
| Accent   |             `#007AFF` |                  `#0A84FF` | links, selection, focus, restrained active indicators |
| Canvas   | fog white / cool gray | graphite, never pure black | application atmosphere                                |
| Success  |        semantic green |             semantic green | run/completed/success only                            |
| Warning  |        semantic amber |             semantic amber | warnings and recoverable risk                         |
| Critical |          semantic red |               semantic red | errors and destructive actions                        |

Primary actions use neutral glass. Accent blue is not a default button fill.

### Typography

- Sans: SF Pro on macOS, Segoe UI Variable on Windows, Inter on Linux/Web.
- Mono: JetBrains Mono.
- Body: `14px / 21px`.
- Secondary: `12px / 18px`.
- Labels: `13px`.
- Code: `13.5px / 20px`.
- Page title: `20px`; section title: `16px`.
- Preserve browser and desktop zoom.

### Spacing and shape

- Base spacing: 4px micro-grid, 8px primary rhythm.
- Rows: 32px desktop; interactive touch targets: at least 44px on narrow/touch layouts.
- Toolbar/titlebar: 44px.
- Panel padding: 16px; content gutters: 20–24px.
- Radius: controls 8px, cards 12px, panels 16px, dialogs 20px.
- Pills are reserved for status, segmented controls, and a few compact quick actions.

### Lines, depth, and icons

- Borders: 0.5–1px translucent hairlines.
- Glass surfaces receive a subtle top inner highlight.
- Shadows are reserved for floating surfaces.
- No colored shadows or glow.
- Rounded outline icons use a consistent 1.5px stroke.
- Sizes: inline/file 16px, toolbar/navigation 18px, important actions 20px, display/empty state 24px.

## Materials

| Surface              | Opacity target | Blur | Notes                                      |
| -------------------- | -------------: | ---: | ------------------------------------------ |
| Sidebar/titlebar     |         40–45% | 18px | native Mica/Vibrancy where available       |
| Main workspace       |         72–76% | 16px | prioritise text and code contrast          |
| Dialog/sheet         |         55–60% | 18px | floating shadow and 20px radius            |
| Popover/menu         |         62–68% | 18px | compact, high contrast                     |
| Code/nested controls |         82–90% | none | inherit the parent glass; never stack blur |

- Windows uses Mica, macOS uses under-window Vibrancy, Linux/Web use CSS glass.
- The background is a light fog or dark graphite field with one faint, static Apple-blue glow.
- Liquid depth comes from one composited blur per structural layer plus static specular highlights and restrained edge refraction. Buttons, messages, code, sticky headers, and nested trays must not add another backdrop blur.
- Windows defaults to GPU composition. `ARFORGE_DISABLE_HARDWARE_ACCELERATION=1` is the explicit compatibility fallback for affected drivers.
- Reduced transparency, software rendering, remote sessions, or sustained dropped frames switch to near-solid, gradient-highlighted materials without geometry changes.
- Expose three quality modes later: Auto, High, Energy Saver.

## Structure

- Wide: collapsible project rail/sidebar (~260px), central session/tabs, on-demand right inspector.
- Medium: sidebar and inspector become overlays.
- Narrow: one session surface with full-screen sheets; composer respects safe areas.
- Medium desktop split panes preserve at least a 240px resize range whenever geometry permits; preferred pane widths relax toward 320px chat / 360px inspector floors before the divider is allowed to lock.
- Sidebar has three states: 56px project rail, expanded panel, and fully hidden focus mode; restore the last state.
- Titlebar is a unified 44px glass band: navigation left, draggable rounded tabs center, operations right, respecting native window controls.
- Conversation and composer share an adaptive 920px desktop column, expanding to 1040px on 2xl surfaces; code, diff, and tables may use the full column.
- Composer is an adaptive glass dock: 64–72px idle and up to 35vh expanded.
- Desktop session panels use an explicit `minmax(0, 1fr) / auto` row contract so the timeline absorbs resize pressure and the composer always remains fully inside the visible panel, including fractional-DPI Windows scaling.

## Interaction

- Hover: 120–180ms; menus: 180–240ms; panels: 240–300ms.
- Enter uses ease-out; exit is slightly faster. Springs are only for direct manipulation such as drag.
- Reduced motion removes non-essential transforms and continuous effects.
- `Ctrl/Cmd+K` opens the command palette. Keyboard operation must be complete and focus must remain visible.
- Popover for light choices, sheet for multi-field flows, modal for credentials/critical/destructive actions.
- Esc closes the top layer, focus is trapped inside modal layers, and returns to the invoking control.
- Success uses a short toast; errors are inline with recovery; long work appears in status center; system notifications only for background completion/action.

## AI conversation and developer surfaces

- User messages use a compact right-aligned glass bubble; assistant responses remain a left-aligned document flow.
- Active reasoning/tools are expanded while streaming. Successful work folds to a grouped summary; failures remain expanded with recovery, retry, and details.
- Code blocks use a near-opaque neutral layer with filename/language/copy/wrap controls. Long blocks can collapse.
- Diff defaults to split when wide and unified when narrow/right-docked, with a manual lock.
- The inspector keeps stable tabs, last tab, and width; badges do not steal focus.
- Terminal opens at the bottom by default, can dock right or detach, remembers its state, and never steals focus.
- Smart scroll follows only while already at the bottom and offers “back to latest” plus unread count after upward scrolling.

## Accessibility and localization

- Default text contrast meets WCAG AA (`4.5:1` for normal text).
- Follow system increased contrast, reduced transparency, and reduced motion; also provide manual controls.
- Reduced transparency uses near-solid surfaces.
- Status always includes icon/text/shape, never color alone.
- Chinese and English follow system by default, allow manual selection, fall back to English, and tolerate text expansion.
- IME composition and code input must not accidentally trigger send.
