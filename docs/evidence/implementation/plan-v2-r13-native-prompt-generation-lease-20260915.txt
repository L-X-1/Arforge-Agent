R13 原生 MCP prompt generation lease（2026-09-15）

结论：native MCP prompt 读取与 ToolRegistry prompt 投影统一使用脱敏 generation lease。服务在 SDK transport 之前校验 server、kind、稳定 capability ID、prompt 名称、当前 generation 与 declared scope；旧代或错配 lease fail-closed，不能触达替换后的 Client。无 generation 历史调用仍保持接口兼容，但同样必须先解析 declared scope，scope 消失时零 transport。

实现：
- packages/arforge/src/mcp/index.ts：MCP.getPrompt 接受 McpCapabilityLease，严格匹配当前 registry 与 scope。
- packages/arforge/src/mcp/resource-projection.ts：prompt Tool.Def 传递完整 lease。
- packages/arforge/src/command/index.ts：MCP slash-command 延迟 getter 传递同一 lease。
- packages/arforge/test/mcp/lifecycle.test.ts：有效 lease、重连后旧 lease 零 transport、错配 ID，以及 scope 消失时无 lease 直读零 transport 回归。

验收：

- resource-projection：11 pass / 0 fail / 48 assertions，exit 0。
