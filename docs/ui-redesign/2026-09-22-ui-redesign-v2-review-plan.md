## 1. 本轮交付与边界

本轮将此前 56 个整页预览统一到同一套视觉语言，并补充 8 个关键状态：浅色模型选择器、深色模型选择器、搜索无结果、模型不可用、全局搜索、项目切换、触屏模型选择器、深色设置。附 7 组总览和旧图归档入口。

这不是业务系统的新版本。所有业务数据、执行输出、连接状态、模型名称都是示例。预览提供局部交互演示，不调用实际模型、不读写真实文件、不运行命令、不发布分享、不更改真实权限。

已确认的选择作为约束；未确认的细节一次性补成推荐，集中供审查。不会把“请设计好”理解为“批准修改界面”。

## 2. 视觉方向

主题是“安静、完整、可控”。使用暖白、石墨、低饱和层次与有节制的衬线标题，不采用大面积炫彩、发光边框、泛滥的卡片阴影、无意义渐变或 AI 装饰图标。

参考 Codex 的项目与会话组织、会话内变更审查，以及 Claude Code Desktop 的工具区域组织思路，但 Arforge 保留自己的全部功能、权限与导航结构，不照搬商标、专有素材或删减功能。

参考资料：[Codex app 官方介绍](https://openai.com/index/introducing-the-codex-app/)、[Claude Code Desktop 官方布局说明](https://claude.com/blog/claude-code-desktop-redesign)。

## 5. 主会话与内容排版

### 5.1 消息结构

用户轻气泡靠右，浅灰底；助手正文无外框。消息角色、运行状态和内容分开，不把工具状态混写成自然语言正文。现有复制、编辑、重试、分支、回退、反馈、分享入口全部保留。

常用消息动作位于回复下方；次要动作在更多菜单中。触屏和键盘不能依赖悬停才能发现操作。动作成功反馈不改变回复正文，不让整条消息跳位。

流式内容保持稳定消息 ID、稳定列表 key 和当前阅读锚点。用户向上阅读后不强拉回底部，显示回到底部入口。新增内容、工具展开和图片尺寸加载完成时尽量保持当前位置。自动滚动阈值与动画属于待审逻辑建议，实施前对齐现有规则。

### 5.2 Markdown 完整性

保留标题、段落、加粗、斜体、删除线、链接、图片、任务列表、有序与无序列表、嵌套、引用、代码、表格、公式和原有扩展。显示样式不能改写 Markdown 原文或编号语义。

代码块推荐提供语言标签、复制按钮和长输出折叠；横向滚动不扩大整个页面。复制输出保持原内容，不附带行号或解释。行内代码与链接清楚区分。链接展示目的域或完整地址的途径，继续遵守外链安全边界。

表格保留语义表头、窄屏独立横向滚动和可访问标签；不能把数字、公式或多行单元格随意截成不可恢复的文本。嵌套列表保持原层级，不改变 start、reversed、value 或任务复选框状态。视觉排序不得重排原始内容。

### 5.3 剩余排版建议

普通正文已确认17px / 1.8；手机建议16px作为单独待审适配，不覆盖桌面选择。内容区域不额外增加首尾空白，间距用相邻内容块总布局规则实现，避免 CSS margin 折叠或两套间距相加。

多段有序条目建议24px分隔，内部段落16px；嵌套列表建议从父级文字列再进24px，但极深层级需要最大可用宽度策略。以上未明确确认的规则都属于 P13，不偷换已确认值。

公式使用原有渲染能力，块公式可横向滚动；来源链接不因为引用衬线样式而失去可辨识性。图片先按已知尺寸占位，加载失败提供重试或受控下载，不展示无限旋转状态。

## 6. 输入框与模型选择器

### 6.1 输入区

双层一体，上层编辑，下层放附件、模型、模式、工具引用与发送。初始2行，增长到8行后文字区域滚动，工具栏保持可见；附件不计算在正文行数内。

保留现有命令、Shell、代理、MCP引用、计划 / 接受编辑 / 完整访问、队列与立即引导能力。默认发送键沿用用户设置；IME组词的Enter不得发送。草稿、光标选区、附件、引用在切换模型或展开面板后保持。

发送过程中防重复提交，但不要把编辑器永久禁用。失败时草稿仍在；区分尚未提交、已排队、服务端接收、正在运行与发送失败。停止按钮说明停止当前回复还是任务，不把取消等同于删除消息。

### 6.2 选择器已确认结构

入口仅模型名加箭头；桌面在上方就近展开，不变暗、不挤动正文。外宽360px，整体上限480px，圆角16px，四边12px内边距。名称14px，ID12px，双行条目最小56px。显示名与ID不同时默认显示ID。当前模型采用勾选和浅底色。

顶部完整搜索框固定，列表独立滚动。按服务商分组，整行标题可折叠，组彼此独立。首次只展开当前模型组；无法识别且无历史记录时全部展开。每个会话分别记忆，同作用域跨刷新 / 重启恢复。新当前模型换组，下次展开新组而保留其他状态。

M01–M38 的逐条记录见矩阵，不在这里以概括替代原条件。

### 6.3 搜索与状态快照

推荐按显示名、原始ID、服务商名称搜索，大小写不敏感、忽略首尾空白、多词AND。普通列表沿配置顺序；搜索时优先名称前缀，再名称包含，再ID或服务商匹配，服务商组顺序稳定。

进入搜索时保存一份分组快照。匹配组展开，无匹配组隐藏。清空恢复原快照；关闭再打开清空关键词。搜索中手动折叠对当前关键词有效；关键词改变时重新展开结果。配置变化时只合并仍有效的稳定ID，不把新组随机混入旧记录。

服务商与模型的唯一键使用稳定providerID + modelID，不能用显示名称拼出唯一性。记忆键至少包含服务器身份、工作区、会话，不包含秘密、API Key或完整带鉴权URL。

### 6.4 选择与真正生效

点击可用条目即确认，成功后自动关闭并回输入框。仅影响当前会话，不改变新会话默认。生成中无排队场景允许切换，当前回复继续原模型，新消息用新模型。

对于排队、定时、重试、子代理，建议在提交时绑定模型 / 服务商快照，已有任务保持显式绑定，重绑定需要明确告知和确认。此规则须核对现有服务契约后实施，不能通过前端标签变化冒充服务端已经切换。

选择失败保持原模型与草稿，不提前关闭或展示成功。选择中锁定本次写入，防重复点击；返回回执后核对会话身份和请求版本，避免慢响应覆盖后续选择。

当前模型被移除、禁用、授权过期或能力不匹配时展示原因，不自动替换成另一个付费或能力不同的模型。无已配置模型显示配置入口；无搜索结果保留关键词和当前选择；异步刷新失败保留最后可用目录并明确其非最新状态。

### 6.5 键盘、关闭与触屏

桌面打开聚焦搜索。Esc在非IME组词时直接关闭并回模型入口；成功选择回编辑器并恢复选区。外部点击只关闭，不透传底层发送、删除或导航。焦点目标消失时使用页面内安全备选，不丢到文档顶端。

推荐方向键在可用模型间导航，Enter确认，Tab覆盖搜索、分组控制、列表与必要恢复入口。分组按钮与模型选项的ARIA结构需按实际组件实现，不用错误的嵌套交互角色拼装。读屏应获得模型名、ID、服务商、选中 / 禁用和原因。

触屏建议底部面板，完整搜索和分组保持；顶部空间不足时不把360px面板挤出屏幕。软键盘出现后基于visual viewport与safe-area重新约束高度。触屏初始是否弹出软键盘推荐不自动弹出，避免面板一打开就遮挡列表，此项仍待审。

## 7. 会话历史导航

位置、可见性、150ms悬停、200ms关闭、提问3行 / 回复4行、触屏显式跳转均按已确认记录。预览直接摘录已存在的内容，不请求模型生成新摘要。

推荐使用消息稳定ID定位。虚拟列表先定位逻辑索引、加载目标页、再对齐真实消息；失败显示可重试状态，不把错误目标标成成功。切换服务器 / 会话时取消悬停定时器与异步加载，避免旧卡片显示到新会话。

刻度密集时推荐聚合显示并提供展开选择，但不删除真实提问。键盘以一个入口进入，方向键移动，Enter或Space执行明确跳转，Esc关闭预览并恢复入口。触屏目标建议至少44px，视觉刻度可以很细，真实命中区域不能重叠造成随机选择。

图片、附件或空文本提问使用真实可读描述；尚无回复显示“暂无回复”，正在回复显示当前已有开头与生成状态。卡片靠可用空间避让，不能挤动正文。关闭按钮和外部点击始终可用，成功跳转后收起。

## 8. 文件、预览、审查与浏览器

### 8.1 工作台

文件树、变更 / 全部文件切换、临时预览、固定标签、中键关闭、拖动宽度、上下文标签和原有审查能力都保留。未保存文件关闭前确认，换服务器或工作区先保护编辑草稿。

预览内容与当前会话引用分开，打开文件不自动添加到消息。用户选择引用时显示路径、版本或来源范围。跨作用域文件必须经过原鉴权适配器，不以本地路径绕过权限。

### 8.2 格式适配

| 内容类型 | 视觉与行为 | 保留限制 |
| --- | --- | --- |
| PDF | 独立纸张画布、页码、缩放、查找、下载 | 渲染失败有恢复；不宣称预览证明真实文件无误 |
| Word | 纸张画布与文档信息 | 不宣称与 Office 原生分页完全一致 |
| 表格 | 工作表、行列头、横向滚动 | 不伪装成完整公式计算或编辑器 |
| 幻灯片 | 缩略图导航、页面舞台、缩放 | 保持实际适配器可支持能力 |
| Markdown / 文本 | 源码与预览、草稿、保存状态 | 冲突先对照，不静默覆盖 |
| HTML / 元素 | 沙箱预览、检查与修改差异分离 | 外链、脚本和元素修改沿用安全边界 |
| 图片 / 音频 / 视频 | 按实际格式显示原有控制 | 不支持格式给原因与受控下载 |
| 差异 | 按文件导航、并排 / 统一视图、行级评论 | 回退先说明文件与对话影响，不混淆两者 |
| 隔离浏览器 | 地址、前进后退、刷新停止、重试 | 桌面能力与会话 / 工作区范围隔离 |


### 8.3 终端与执行

执行详情采用步骤导航与宽内容区，不将说明挤成一两字宽列。输入、输出、错误、耗时、来源与历史运行分区，长输出可折叠但保留全文和复制。

终端沿用PTY与原有后端，不用网页模拟输出替代真实终端。保留多标签、缩放、调整尺寸、重连与停止范围。此次不改CLI/TUI。设计图中的终端与运行记录均为样例文本。

## 9. 会话运营页面

| 领域 | 必保留字段与能力 | 关键边界 |
| --- | --- | --- |
| 目标与任务 | 目标状态、依赖、领取、负责人、revision、完成证据 | 忙碌限制与修订冲突不能删除 |
| 消息队列 | FIFO、编辑、移除、投递回执、绑定模型 | 排队与立即引导明确区分 |
| 定时消息 | 时间、Cron、时区、错过执行、启停、手动运行 | 手动运行仍受空闲 / 权限约束 |
| 触发器 | 来源、条件JSON、模板、试运行、状态 | 输入校验、去重和秘密遮蔽 |
| 等待 | 原因、来源、唤醒条件与回执 | 不能把等待显示成虚假进度 |
| 团队与子代理 | 成员、依赖、隔离消息箱、跟进、取消 | 不得跨成员泄漏消息或取消错误运行 |
| 检查点与回退 | 命名、消息锚点、范围预览、确认、回执 | 对话回退不撤销文件 / Git / 命令 / 外部状态 |

| 后台任务 | 批准、启动、暂停、恢复、取消、删除、已读 | 生命周期动作独立，不以删除代替取消 |


所有列表均设计空、加载、过滤无结果、错误、无权限、分页、选中、写入中和冲突状态。详情保留来源与作用域；操作完成后以服务端回执更新，不仅靠乐观样式假装成功。

服务商、模型、服务器、权限、记忆、受控进化、运行时、代理、技能、插件、工作流、MCP、诊断、运维、能力映射、治理、产物均保留原有归属。详细字段与风险规则见页面清单。

技能与插件的安装、更新、启停、卸载、恢复分别确认；候选评测、批准、灰度、推广和回滚按真实生命周期。MCP目录、资源引用与工具可见性继续受鉴权控制。内部transport、发现、对账等能力不为凑界面而增加直接操作按钮。

设置保留语言、UI / 代码 / 终端字体、字号、主题、颜色方案、推理与工具显示、移动标题栏、文件树 / 搜索 / 状态栏、代理可见性、Shell、通知、声音、更新、发布说明、引导、快捷键以及发送队列 / 引导偏好。

## 11. 全局状态与安全交互

| 状态 | 展示内容 | 恢复与保护 |
| --- | --- | --- |
| 初次加载 | 稳定骨架、内容类型、真实加载原因 | 不伪造百分比；超时给重试 |
| 空数据 | 说明没有内容，不写成错误 | 给一项合适的主要入口 |
| 筛选无结果 | 保留筛选条件和作用域 | 清空筛选，不删除配置 |
| 离线 / 重连 | 最后可用内容与状态时间 | 保留草稿，避免重复提交 |
| 认证过期 | 清楚说明服务商 / 服务器 | 重新授权，不泄露秘密 |
| 无权限 | 请求来源、对象和受限动作 | 联系管理员或切换身份，不诱导提权 |
| 写入中 | 禁用重复提交，其他编辑按规则保留 | 明确取消是否可用 |
| 保存冲突 | 本地草稿与远端版本 | 对照 / 重新加载 / 明确覆盖 |
| 模型不可用 | 原因与当前绑定 | 不静默降级，不宣称已发送 |
| 数据库迁移阻塞 | 版本、角色、脱敏日志、安全说明 | 不自动使用管理员连接迁移 |
| 危险操作 | 精确对象、范围、后果、确认按钮 | 默认安全选择，保留审计与撤销边界 |
| 更新 | 版本与变更、重启要求 | 尊重更新偏好，保护草稿 |
| 部分失败 | 成功和失败分别列出 | 只重试失败对象，避免重复副作用 |


确认框使用具体动作名称而非泛泛“确定”。允许一次与持久授权分开；默认不扩权。外部关闭、Esc、重复点击和多窗口并发必须明确处理，不能触发底层危险按钮。

## 13. 无障碍与微动效

以语义HTML和实际组件能力为基础，采用清晰焦点、逻辑Tab顺序、正确的dialog / combobox / listbox语义、命名和状态播报。颜色必须同时有文字、图标或形状表达状态。

加载与成功播报克制，流式内容不让读屏反复全文重读；错误聚焦到可操作位置。高对比和减少动态效果可用。建议过渡140ms，避免仅为了“高级”而使用多层弹簧、闪烁光点和持续漂浮。

本次未执行正式对比度计算、读屏、完整键盘或200%缩放测试，不把设计建议写成已经合规。实施时再按批准范围做针对性验证。

## 14. 技术实现与逻辑优化方案

继续使用现有 SolidJS 框架、服务端连接上下文、共享Provider和路由能力，不为了换视觉引入另一整套框架或重写后端。

| 层 | 计划方法 | 不变项 |
| --- | --- | --- |
| 设计令牌 | 集中CSS变量：颜色、间距、字族、圆角、层级、状态 | 显式偏好与已确认参数优先 |
| 共享组件 | 按钮、字段、列表、选择器、弹层、提示、状态页统一 | 不删除已有动作与ARIA语义 |
| 框架布局 | 分离全局壳、会话主区、工具区、管理二级导航 | server identity 与 originatingSessionID |
| 会话内容 | 稳定消息ID与类型渲染；内容间距规则化 | Markdown语义、历史定位与流式协议 |
| 输入状态 | 草稿、附件、模型、模式、队列状态分离 | 现有命令、发送模式、权限 |
| 选择器状态机 | closed / browsing / searching / selecting / failed | 已确认焦点、关闭、记忆和生效条件 |
| 异步请求 | AbortController / 版本令牌 / 明确scope检查 | 不跨会话覆盖，不吞掉错误 |
| 写入动作 | 保留revision / 幂等键 / 确认回执 | 危险操作预览、审计与空闲限制 |
| 文件预览 | 按需加载适配器，分离文件身份和显示状态 | 鉴权、只读、外部打开与未保存保护 |
| 设置迁移 | 版本化补缺省，保留显式值与恢复策略 | 不清除无关配置 |
| 性能 | 稳定key、局部订阅、重预览延迟加载、节制DOM | 30倍压力问题单列，不宣称因此解决 |
| 可回退 | 按模块替换、清晰迁移和回退记录 | 不执行Git重置、不覆盖用户改动 |


重点约束：不要在普通会话切换时重挂全局服务Provider；服务器身份变化才按既有边界隔离。慢请求回调必须核对来源作用域。表单保存失败保留输入；前后台窗口不能无提示互相覆盖。展示值和真实业务状态分离，UI选中样式不是成功回执。
