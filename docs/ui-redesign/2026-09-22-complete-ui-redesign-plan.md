## 4. 信息架构与默认展开策略
1. 全局壳层：平台标题栏、工作区选择、会话列表、全局搜索、设置和控制中心入口。保留标签、前进后退、多窗口及现有快捷键。
2. 会话中心：消息、输入区、左侧提问刻度、精简状态行。默认不展开文件树、执行长日志和管理表格。
3. 工作台：文件树、文件标签、变更审查、上下文、终端、预览、桌面隔离浏览器。沿用已有拖动、调整尺寸、外部打开、关闭和恢复机制。
4. 会话管理：目标任务、待发送消息、定时、触发、等待、团队、子代理、检查点、回退、后台任务、反馈。带上原始会话和服务器上下文。
5. 控制中心：个人工作区、概览、权限、记忆、演化、运行时、扩展、诊断、运维、能力映射及已有治理/产物子工作台。
6. 设置：通用、外观、快捷键、服务器、服务商、模型、通知、声音、更新、引导与现有显示开关。
7. 窄窗口：只保持一个主阅读面板，导航用抽屉，辅助工作台以切换或覆盖方式打开。不是删除功能或在窄屏隐藏入口。
8. 所有低频功能至少有设置/管理页或命令面板入口；不会以“简洁”为理由删除能力。

### 5.1 字体、偏好和资源
- 中文：按第 3 节的语义角色继承，不因消息长度自动换字体。
- 英文推荐按语义配套：普通正文/UI 使用 Noto Sans；标题、引用和有序列表使用 Noto Serif。编号继续使用已选 Noto Sans SC；代码使用 JetBrains Mono，缺失时回退到可用系统等宽字体。
- 不打包苹果专用字体，不用 SF 字体可用性作为跨平台前提。字体版本、授权文件与分发方式在实施引入资源前核查；本地字体预览不是分发授权证明。
- 已有自定义字体、字号、缩放优先；新默认值只在未设置时采用。不通过重置 settings.v3 或其他存储来应用新视觉。
- 不在字重不支持时静默假定实际效果相同。实施需检查实际字体加载、缺字和回退。

## 6. 关键交互完整说明

### 6.1 输入区与消息
- 编辑区 17px / 26px 行高，2 行开始、最多 8 行，文本区域约 52-208px；工具栏持续可见，整体高度随字号设置计算。
- 保留文件/图片附件、粘贴、拖入、文件和 MCP 引用、已有代理选择、模型选择、推理选项、命令、Shell 模式、项目/工作区上下文、编辑与重发、历史输入。
- 工具入口收纳为加号菜单和上下文芯片，不删除操作；权限模式使用明确文字，不用颜色暗示已获得执行授权。
- Enter 发送、Shift+Enter 换行仅作为未设置时的默认行为；IME composition 时 Enter 只用于选字。旧快捷键优先。
- 运行中保留停止、排队和已有 steer 语义；队列按真实 FIFO 顺序展示，不能将队列发送伪装成立即生效。
- 发送成功后才清理对应草稿；失败、断线、额度限制保留输入、附件与关联项目。
- 保留复制、反馈、重试/重生成、编辑、分支、分享/撤销、跳转与现有消息级操作。无权限或条件不满足时显示原因，不悄悄删除入口。

### 6.2 历史提问导航
- 左侧刻度宽度视觉 9-17px，交互区域扩大；默认低对比度常驻，当前项对比度增强。
- 桌面卡片默认 320px 宽，边界不足时向阅读区内侧避让；不改变正文布局或阅读宽度。
- 鼠标显示与关闭延迟、内容行数、触屏规则严格沿用第 3 节。
- 键盘只保留一个 Tab 入口；上下键选取并预览，不滚动正文；Enter/Space 跳转，Escape 关闭，下一次 Tab 离开。卡片有焦点时不因指针离开自动关闭。
- 点击跳转采用消息稳定 ID 和滚动锚点；定位偏移考虑固定标题栏。定位后轻量高亮 1.2 秒，减少动态偏好下取消平滑移动。
- 历史尚未加载先展示加载状态，加载成功后再定位；失败给出重试，不能跳到错误的同序号消息。
- 超长历史用虚拟化或分组刻度，保留所有提问的可达性；分组提供完整列表，不把看不见的刻度视为可删内容。
- 手机轻点刻度先打开卡片，触屏卡片不自动计时关闭；提供关闭和跳转按钮，成功跳转后再收起。

### 6.3 文件、预览与终端
- 保留文件树的全部/变更筛选、搜索、单击预览与固定标签差异、标签关闭/中键关闭、排序、外部应用打开和宽度调整。
- 文件、变更、上下文和浏览器保持独立状态，切换不丢原始位置。隐藏面板不产生第二套 Server 或 SSE 实例。
- PDF 保留页码、缩放、搜索、下载与失败恢复；Office 保留已支持格式的视图及外部打开，不宣称原生 Office 完美分页或完整编辑能力。
- Markdown/文本编辑保留草稿、保存中、保存失败、外部文件变化、冲突比较和取消；保存成功以服务器回执为准。
- HTML/元素预览保留沙箱、资源策略和作用域，选择元素、编辑内容、影响预览与写入确认分开。
- 不支持的附件明确显示类型与无法预览原因，保留下载/外部打开，不用空白面板代替错误。
- 桌面隔离浏览器保留导航、后退前进、刷新、停止、关闭及所有权；Web 没有原生能力时说明差异，不伪造相同能力。
- 终端展示连接/启动/重连/退出状态，保留标签与 PTY 生命周期；不能打开黑窗口就宣称启动成功。

### 6.4 管理、审批与高风险操作
- 每页显示服务器、工作区、会话或租户的真实作用域；切换时取消或隔离旧请求，禁止旧结果写入新页面。
- create/update/delete 与 read 分类不变，所有现有 revision、owner、身份和权限检查继续由现有 typed API 执行。
- 安装与启用、预览与执行、评测与推广、批准与实际运行保持分离。
- 对话回退只归档后续消息；“会话与文件回退”属于另一个高风险流程，显示真实文件影响并沿用审批。
- 记忆候选、纠错、冲突与撤销保留证据和理由；自动学习不能覆盖明确的用户事实。
- 数据政策、备份、验证、秘密撤销与审计导出保持范围提示；缺失/未验证显示为未知或待验证，不伪报通过。
- MCP 发现、对账维护和产物字节读取的内部语义维持内部边界，不为覆盖矩阵好看而增加普通执行按钮。
- 数据库迁移显示管理员执行指引、错误与日志，不自动使用管理员 URL，不一键重置或隐式删除数据。

## 7. 全局状态规范
| 状态 | 必须展示 | 恢复与保留 |
|---|---|---|
| 首次/路由加载 | 当前步骤、占位形态、必要时耗时；禁止纯黑/纯白且无解释 | 超时后恢复入口，不假装完成 |
| 空列表 | 为什么为空、清晰下一步 | 保留搜索条件与已有导航 |
| 空搜索 | 当前关键词、清除筛选入口 | 不把无结果当作没有数据 |
| 离线/连接失败 | Server 名称、连接阶段、错误摘要 | 重试、更换服务器、日志；草稿与滚动锚点保留 |
| 认证/额度 | 分清认证、计费、权限、连接问题 | 重新授权或对应设置，不清空输入 |
| 权限不足 | 操作对象、受限原因、可用替代 | 不自动切换全权限 |
| 保存冲突 | 本地稿、远端版本、差异和来源 | 先比较，不静默覆盖 |
| 请求过期 | 已变化的对象或 revision | 重新预览，不复用旧确认 |
| 运行/等待/阻塞 | 状态来源、原因、步骤；不造假进度 | 现有停止、唤醒或跟进能力 |
| 成功与失败 | 回执 ID、影响范围或可理解错误 | 恢复后保持上下文，支持重试但不重复危险写操作 |
| 删除/撤销 | 明确对象、不可逆说明或恢复范围 | 取消默认可达，危险确认不自动勾选 |
| 更新/重启 | 新版本状态和未保存内容 | 用户确认后执行，不因设计切换触发重启 |

## 8. 响应式、平台与可访问性
- >=1280px：完整侧栏和阅读区域，可展开辅助工作台；正文不是无限拉长。
- 700-1279px：侧栏收窄/折叠，工作台优先单主面板；保留开关和当前选择。
- <700px：抽屉导航、单列聊天、全宽输入和按需预览；底部安全区域、软键盘及已有移动标题栏偏好保留。
- 触屏目标至少 44px；按钮文字和图标有可访问名称；弹窗焦点圈定、关闭后恢复原焦点，Escape 规则保持一致。
- 控件、状态、选中和错误不只靠颜色；正文与控制对比度以 WCAG AA 为实施验收目标，本原型不宣称已获得完整可访问性验收。
- 200% 缩放、长中文/英文、RTL（如现有支持）、系统高对比度、减少动态与键盘全流程列入实施验证。
- Windows 保留本机窗口按钮和应用菜单；macOS 使用自己的系统菜单行为，不为了仿苹果在 Windows 加假交通灯按钮。
- Web 使用浏览器能力，不请求不存在的桌面桥接接口；不可用动作显示理由和安全替代。

## 9. 逻辑优化与实施架构
- 在现有 Solid 组件和 UI 包上分层改造，不为视觉另建业务状态源或更换框架。
- 设计 Token 与语义组件先落地，再迁移壳层、会话、预览和管理页；不采用全局宽泛选择器一次覆盖所有页面。
- Server / Session 身份保持现有 router 与 Provider 边界，尤其不在会话切换时重建服务器子树，避免重复请求、丢失草稿或新旧结果串线。
- 读请求具备取消或身份校验；写请求保留幂等、revision 与现有确认边界，失败时展示真实回执，不以 UI 乐观完成替代执行成功。
- 面板可见性、滚动、选中和编辑草稿分别建模，派生数据按最小范围更新，避免全量消息重渲染。
- 长会话保留虚拟化、稳定 row key、Markdown 缓存与滚动锚点；正在阅读旧消息时不强行滚到底部。
- 编号列按列表批次测量，流式过程中只在必要时增大已测最大宽度，完成后统一收敛；不逐 token 反复测量全部行。
- 控制中心表格、日志与资源按需加载和分页，隐藏工作台停止不必要的观察与派生工作，但不随意终止用户真实任务。
- 预览按格式懒加载，解析失败隔离在当前文档；保留资源 URL、沙箱和所有权策略。
- 菜单/命令/工具栏调用同一现有 action owner，不复制操作实现以致多个入口行为漂移。
- 错误模型统一为可理解摘要、具体原因、影响范围、恢复路径和可复制技术信息；秘密信息遮蔽。
- 设置迁移版本化、可回滚、尊重已有值；不把清空存储当作迁移方案。

## 10. 批准后的实施顺序与退出条件
| 阶段 | 修改范围 | 退出条件 |
|---|---|---|
| R0 设计冻结 | 审查意见、差异和待批准变更 | 用户明确说“执行重构”；未批准部分不擅自修改 |
| R1 基础 Token | 主题、字体角色、密度、可访问基础组件 | 浅深色和已有设置兼容，受影响组件最小验证通过 |
| R2 壳层与导航 | 标题栏、项目/会话、设置与控制中心入口 | 所有现有页面可达，路由/会话/Server 身份不串线 |
| R3 会话核心 | 消息排版、输入、历史刻度、工具详情 | 发送、编辑、队列、停止、IME、键盘/触屏历史均保留 |
| R4 工作台 | 文件、diff、文档、浏览器、终端 | 原文件不受视觉切换影响，保存/冲突/下载/权限边界正确 |
| R5 管理功能 | 目标、团队、定时、记忆、扩展、治理、设置 | 保留矩阵逐项回归；危险操作有真实预览和确认 |
| R6 跨尺寸与异常 | 手机、窄窗口、深色、离线与加载 | 无不可达控件或文字遮挡，恢复后上下文正确 |
| R7 整体回归 | 功能、可访问性、正常负载性能、设置迁移 | 先最小测试/typecheck 再必要的浏览器与桌面验收；不关闭类型检查绕过问题 |
| 独立专项 | 30 倍极限压力 / 安装包 | 性能问题保持未通过；安装包按用户要求继续延期，二者不伪装为 R7 已完成 |

本计划没有执行上述任何应用实施阶段。后续文件改动仍需遵守包级规范、保留既有用户修改、保持小步和可回滚。
